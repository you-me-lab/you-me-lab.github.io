**Политика конфиденциальности:** https://you-me-lab.com/privacy/

**Правила обхода:** https://you-me-lab.com/robots.txt

## Архитектура и публикация

Канонический репозиторий исходников: https://github.com/you-me-lab/you-me-lab.github.io, ветка `main`. Утверждённая схема размещения — **GitHub → Netlify → you-me-lab.com**; проект Netlify: `glistening-horse-a7aa1c`. DNS остаётся под управлением REG.RU. Использование GitHub Pages в качестве рабочей платформы прекращено.

22.10.2026 независимо проверен раздел Netlify Domain management: основной домен `you-me-lab.com`, `www` настроен на автоматическое перенаправление к основному домену; HTTPS включён, сертификат Let's Encrypt охватывает оба домена, автопродление до 20.01.2027. Открытая главная страница по HTTPS доступна в браузере владельца. По его передаче SSL Labs выставил A+; это отдельно не воспроизведено. Фактический ответ HTTP-редиректа `www`, внешнюю доступность для поисковых роботов и индексацию подтвердить дополнительно. Старая диагностика GitHub Pages больше не применяется.

## Дизайн и контент

Утверждённый дизайн: **v1.1**, 20.10.2026 (D186). Владелец сообщил о визуальном принятии опубликованного сайта 22.10.2026 на ширинах 320 / 768 / 1440 px без замечаний. Без отдельно выявленных дефектов редизайн не проводить.

Сайт информационный, без регистрации, собственных форм сбора данных, рекламных скриптов и веб-аналитики (по версии исходников на 22.10.2026). Главная страница содержит разделы игр, студии и будущих продуктов. Публичные названия — **«Я никогда не»** и **«Кто скорее?»**. Ссылка RuStore для первой игры: https://www.rustore.ru/catalog/app/com.youmelab.neverme . Для второй игры действующая ссылка загрузки появится только после подтверждённой публикации в RuStore.

Файлы: `index.html`, `styles.css`, `script.js`, `privacy/index.html`, `assets/`, `sitemap.xml`, `robots.txt`. В `index.html` задано изображение Open Graph `assets/og-cover.png` (1200×630). Обновление предпросмотра Telegram 22.10.2026 ещё не подтверждено из-за кеширования Telegram.

Политика утверждена D192, исходник `privacy/index.html`, редакция 21.10.2026. Обработку AppMetrica в будущих версиях игр отражать в новой редакции политики по фактическим настройкам приложения. Контакт поддержки: support@you-me-lab.com.
