# YouMeLab — официальный сайт

Официальный информационный сайт YouMeLab: https://you-me-lab.com/ — исходники развёрнуты через GitHub Pages. **Состояние DNS/HTTPS проверять отдельно**: на последнем предоставленном скриншоте GitHub Pages показывал `InvalidDNSError` (21.10.2026).

Утверждённая владельцем версия дизайна: **v1.1** (20.10.2026, Decision Log D186). Публикация согласована 20.10.2026.

Содержимое сайта: `index.html`, `styles.css`, `script.js`, `assets/` (фирменная графика, оптимизированные иллюстрации, шрифты Rubik), `.nojekyll`. Работает без аналитики, сторонних сценариев и серверной части. Набор без исходных тяжёлых PNG: оригиналы сохранены в каноническом исходном архиве на Google Drive. Лицензия шрифта — `assets/fonts/OFL.txt`.

Канонический исходный архив (в том числе оригинальные PNG и снимки для проверки): https://drive.google.com/file/d/1sccs53YOmXlpHntgJAVwmQNsOqt-kUcG/view

**Политика конфиденциальности утверждена владельцем и опубликована в репозитории (D192)**: [`/privacy/`](https://you-me-lab.com/privacy/), исходный файл `privacy/index.html`, редакция 21.10.2026. Доступность страницы по HTTPS пока требует отдельной внешней проверки после DNS-ошибки. В главном `index.html` есть ссылка на политику. Контакты: support@you-me-lab.com.

Актуальные статусы и правила передачи между чатами — в [Master Plan](https://docs.google.com/spreadsheets/d/1dmCXnwTSkdScOIieWhw11SDeVlWcjGtjfBYoVqi0754/edit) и [START HERE](https://docs.google.com/document/d/1Q7DP_xupx__7A8Qe0RRn4eKp7PfYEgZO4m8PouFTRcs/edit) (D194).

Файлы не содержат секретных ключей или сборок Android. Приложения разрабатываются в отдельном закрытом репозитории.
