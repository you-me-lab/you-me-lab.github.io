# YouMeLab — официальный сайт

Официальный информационный сайт YouMeLab: https://you-me-lab.com (настраивается через GitHub Pages).

Утверждённая владельцем версия дизайна: **v1.1** (20.10.2026, Decision Log D186). Публикация согласована 20.10.2026.

Содержимое сайта: `index.html`, `styles.css`, `script.js`, `assets/` (фирменная графика, оптимизированные иллюстрации, шрифты Rubik), `.nojekyll`. Работает без аналитики, сторонних сценариев и серверной части. Набор без исходных тяжёлых PNG: оригиналы сохранены в каноническом исходном архиве на Google Drive. Лицензия шрифта — `assets/fonts/OFL.txt`.

Канонический исходный архив (в том числе оригинальные PNG и снимки для проверки): https://drive.google.com/file/d/1sccs53YOmXlpHntgJAVwmQNsOqt-kUcG/view

Политика конфиденциальности ещё не опубликована; на сайте обозначена как готовящаяся. До утверждения правовой версии не добавлять фиктивные ссылки. Контакты: support@you-me-lab.com.

Файлы не содержат секретных ключей или сборок Android. Приложения разрабатываются в отдельном закрытом репозитории.
